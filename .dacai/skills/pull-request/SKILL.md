# Pull Request

1. Inspect `git status` and the scoped diff.
2. Run required validation.
3. Stage only intended paths.
4. Commit with a concise message.
5. Push only the current branch to `origin`.
6. Open a draft PR.
7. Report branch, commit, validation, and PR result.

Never rewrite unrelated history or force-push through these skills.
